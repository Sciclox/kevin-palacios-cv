## 🌟 Overview

---

## ✨ Features

- **Dynamic Theme Engine**: Toggle seamlessly between Dark and Light color palettes with smooth transitions.
- **Typography Switching**: Switch between modern sans-serif (Inter / Plus Jakarta Sans) and classic editorial serif (Lora) typography.
- **Performance Optimized**: Zero heavy dependencies; instant First Contentful Paint (FCP) and 100/100 Lighthouse performance score.
- **Responsive Layout**: Fluid CSS grid and flexbox layout adapting to smartphones, tablets, and desktop displays.
- **Interactive Sections**: Project showcase, skill matrices, professional timeline, and interactive contact actions.
